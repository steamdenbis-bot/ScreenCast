# ScreenCast — трансляция экрана ПК на Android TV

Две программы:

- `pc/` — программа для Windows (Python): захватывает экран, сжимает в JPEG и шлёт на ТВ по локальной сети. Там же кнопки установки приложения на телевизор через ADB.
- `android-tv/` — приложение для Android TV: принимает кадры и показывает их на весь экран. Появляется в списке приложений ТВ как «ScreenCast TV».

## Шаг 1. Собрать APK для телевизора

**Вариант А — через GitHub, ничего не устанавливая:**
1. Создайте репозиторий на github.com и загрузите в него всё содержимое папки `ScreenCast` (папка `.github` должна оказаться в корне репозитория).
2. Откройте вкладку **Actions** → сборка «Build ScreenCast TV APK» запустится сама (или нажмите **Run workflow**).
3. Через 3–5 минут откройте завершённый запуск и скачайте артефакт `ScreenCastTV-apk` — внутри `ScreenCastTV.apk`.

**Вариант Б — Android Studio:** File → Open → папка `android-tv` → дождаться синхронизации → Build → Build APK(s). Файл появится в `android-tv/app/build/outputs/apk/`.

## Шаг 2. Включить отладку на телевизоре

1. Настройки → Настройки устройства → Об устройстве → 7 раз нажать на «Сборка» (Build).
2. Назад → «Для разработчиков» → включить **Отладка по USB** (на некоторых ТВ ещё есть отдельный пункт «Отладка по сети / ADB over network» — его тоже).
3. Узнайте IP телевизора: Настройки → Сеть → ваша сеть.

## Шаг 3. Подготовить ПК

1. Установите Python 3.9+ с python.org (галочка «Add Python to PATH»).
2. Скачайте **Android SDK Platform-Tools for Windows** с developer.android.com/tools/releases/platform-tools и распакуйте папку `platform-tools` в `pc/` (рядом с `screencast_pc.py`).
3. Положите `ScreenCastTV.apk` в `pc/`.
4. Запустите `start.bat` (первый раз он сам поставит `mss` и `pillow`).

## Шаг 4. Установить и транслировать

1. Введите IP телевизора.
   - Если на ТВ пункт **«Беспроводная отладка»** (Android 11+): на ТВ откройте «Сопряжение устройства с помощью кода», впишите в программе «IP:порт» и код из этого окна → **0. Сопряжение**. Программа сама попробует найти порт для подключения; если не найдёт — впишите в поле «IP-адрес ТВ» строку «IP-адрес и порт» с главного экрана беспроводной отладки (порт там другой).
2. **1. Подключиться по ADB** — на ТВ появится «Разрешить отладку?» → «Разрешить» (с галочкой «Всегда»). Нажмите кнопку ещё раз.
3. **2. Установить APK на ТВ** — приложение установится и откроется.
4. **▶ Начать трансляцию.**

Дальше ADB уже не обязателен: можно просто открыть «ScreenCast TV» пультом и нажать «Начать трансляцию» — IP показан на экране телевизора.

## Советы

- Лучше всего — ТВ по кабелю или ПК и ТВ на Wi-Fi 5 ГГц.
- Если картинка подтормаживает: уменьшите ширину до 960–1280 или качество до 50–60.
- Задержка обычно 100–250 мс: для фильмов, презентаций и браузера подходит, для динамичных игр — не очень.
- Звук не передаётся (только изображение).
- Брандмауэр Windows может спросить разрешение для Python — разрешите для частной сети.
- Сделать `.exe`: запустите `build_exe.bat`, готовый файл будет в `pc/dist/`.

## Как это устроено

ТВ-приложение слушает TCP-порт **8765**. ПК подключается, шлёт `SCRN`, затем кадры: 4 байта длины (big-endian) + JPEG.
